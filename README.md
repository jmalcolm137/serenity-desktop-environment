# Serenity Desktop Environment (SDE)

A project to recreate the **SerenityOS desktop experience** on **Wayland** and **Linux**.

SerenityOS describes itself as "a love letter to '90s user interfaces". SDE is a love letter to SerenityOS.

![The SDE desktop: the SerenityOS Taskbar with its system menu (Development) open, a Terminal running `uname -a` / `df -Th`, the active File Manager, the Browser on serenityos.org, and the System Monitor's Performance tab, on the SerenityOS grid wallpaper. The screenshot is generated by `scripts/run-desktop-scene.sh --headless --screenshot docs/images/sde-desktop.png`.](docs/images/sde-desktop.png)

SerenityOS describes it's rough goals to be "a marriage between the aesthetic of late-1990s productivity software and the power-user accessibility of late-2000s *nix". The SerenityOS UX does an amazng job of capturing the aesthetic. That said, we believe "the power-iser accessibility of late-2000s *nix" is best expressed by modern Linux with its broad hardware compatibility, vast software catalog, and container ecosystem. The goal of SDE is to faithfully recreate the SerenityOS UX on Linux.

The stack is split across a small family of repositories:

| Repository | Role |
|---|---|
| [`SerenityOS/serenity`](https://github.com/SerenityOS/serenity) | Upstream source of LibGUI / LibGfx / applications / themes / fonts. Consumed **unmodified** wherever possible. |
| [`jmalcolm137/libgui-wayland`](https://github.com/jmalcolm137/libgui-wayland) | **LibWindowServer**: runs unmodified Serenity `LibGUI`/`LibGfx` apps natively on Wayland by implementing the WindowServer protocol in-process. |
| **this repo** | The **system side**: `WindowServer` (a [reasonably complete](docs/23-wayland-protocols.md) wlroots-based Wayland compositor) and the session that runs the **unmodified SerenityOS shell apps** (Taskbar, applets, Desktop, Settings) as Wayland clients, plus services/settings and the integration that turns LibWindowServer-powered apps into a coherent desktop session. |

## Running

**Building from scratch.**

```sh
scripts/build-full-sde.sh --with-apps
```

**Real hardware (DRM/KMS + libinput).** From a TTY (`Ctrl+Alt+F3`) or a display
manager session entry:

```sh
scripts/start-sde-session.sh
```

**Display manager (SDDM, GDM, ...).** Install the session entry so the login
screen lists **Serenity Desktop Environment**:

```sh
sudo scripts/install-session.sh    # /usr/local/bin/sde-session + /usr/share/wayland-sessions/sde.desktop
# ... then log out and pick it at the login screen.
# Remove it with: sudo scripts/install-session.sh --uninstall
```
